Glossary

Every technical term in the lessons, in plain English. Inside a lesson, hover or tap a dotted term to see its definition in the margin.

A
Activation function A simple non-linear function (such as ReLU, sigmoid or tanh) applied to each neuron's weighted sum. Without it, stacked layers collapse into a single linear model. Taught in 1.2 · used in1.2 · 1.3 · 3.2 On the map
Adam A popular optimizer that gives every parameter its own adaptive step size, using running averages of recent gradients and their squares. AdamW is Adam with weight decay applied correctly. Taught in 3.1 · used in1.1 · 1.2 · 1.3 · 2.3 · 2.4 · 3.1 On the map
Architecture The design of a network — which layers, how many, how wide, and how they connect. It encodes built-in assumptions about the data. Taught in 2.3 · used in1.1 · 1.3 · 2.3 · 2.4 · 3.1 · 3.2 On the map
B
Backpropagation The algorithm that computes the gradient of the loss with respect to every parameter, by applying the chain rule backwards through the computational graph. It assigns "credit" or "blame" to each parameter. Taught in 1.2 · used in1.1 · 1.2 · 1.3 · 2.3 · 3.1 · 3.3 On the map
Baseline A simple reference result (e.g. always predicting the majority class, or a logistic regression) that any serious model must beat to be worth its cost. Taught in 2.3 · used in2.2 · 2.3 · 2.4 · 3.4 · 4.2 · 4.4 On the map
Batch A small group of training examples processed together in one forward and backward pass. The batch size is how many examples it contains. Taught in 2.2 · used in1.2 · 1.3 · 2.1 · 2.2 · 2.3 · 2.4 On the map
Bias (parameter) A learned number added to a neuron's weighted sum, letting it shift its output independently of the inputs — like the intercept in linear regression. Taught in 1.2 · used in1.1 · 1.2 · 1.3 · 2.1 · 2.3 · 3.3 On the map
Broadcasting The rule that lets tensors of different shapes be combined element-wise by virtually stretching size-1 dimensions. Powerful, and a source of silent bugs when shapes are not what you think. Taught in 2.1 · used in1.2 · 1.3 · 2.1 · 2.4 On the map
