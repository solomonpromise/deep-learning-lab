# Replacement Modules 5–6: reviewed visual resources

37 educational infographics were generated with the built-in `image_gen` tool,
using the earlier CNN and Transformer illustrations as style references. All 37
user briefs are covered. Six additional numerical figures are generated by
`scripts/figures/module56_worked.py`; they accompany the app's paused walkthroughs.

`manifest.json` records placement, captions, alternatives, dimensions and hashes.
`provenance.json` records the original briefs, exact augmented prompts, revision
requests, generated source paths and selected workspace assets. Generation and
revision logs preserve discarded variants' provenance; discarded images remain
at their original generated-image paths rather than in this directory.

The selected PNGs are copied into this workspace and embedded as attachments in
the canonical notebooks. The notebooks and their app downloads work offline for
reading; the app's interactive enhancements have static worked companions there.
Original author folders and the earlier loved image assets remain untouched.

Conceptual feature maps, shared spaces and attention weights are illustrative.
The reference-run comparison scores in figure 5.1.4 are supplied notebook results;
all actual experimental plots and measurements remain the code's saved outputs.
Review corrected dimensions, cell/attention data flow, pre-norm residual branches,
token counts, projection caveats, and the separate training/generation loops.

The app walkthroughs use fixed, stated examples with Previous/Next, Play/Pause and
Reset controls. They start paused, stop off-screen and in hidden tabs, and use a
slower discrete sequence under reduced-motion preferences. They do not run a
trained model or fabricate experimental results.
