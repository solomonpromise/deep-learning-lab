How to use this platform

A two-minute tour of what is on every lesson page and how to get the most from it.

1

Read the lesson top to bottom

Each lesson opens with its goal, what you will be able to do by the end, and the data it uses. Then it walks through numbered sections. The On this page panel on the right tracks where you are, and the bar under the top menu shows how far through the lesson you have read.

2

Play with the interactive labs

Boxes marked Interactive are live experiments that run in your browser. Move the sliders, press play, break things on purpose. Each one is placed exactly where the idea it demonstrates is explained.

3

Answer the questions, then check yourself

Question cards come in three flavours: Check your understanding, Pause & think and Try it yourself. Press Write my answer to jot down your thinking (saved on this device only), then Show explanation to compare it with a full worked answer.

4

Read the code and its output

Every code cell from the notebook is here, with the output it actually produced. Some cells carry a line-by-line explanation: numbered markers on the code match the notes underneath. Long code and long outputs are folded; click to expand. The copy button copies the whole cell.

5

Look up any term

Words with a dotted underline have a definition. Hover (or tap on a phone) to read it. The glossary lists them all.

6

Run it yourself

Every lesson has a Download notebook button. Open it in Jupyter, VS Code or Google Colab and run the cells. Reading builds understanding; running and changing the code is where it sticks.

7

Track your progress

Press Mark lesson as complete at the end of each lesson. Completed lessons get a tick in the sidebar and on the course map. Progress lives in this browser, so no account is needed.

Keyboard shortcuts

  • ⌘ K or / — search
  • ← → with Alt — previous / next lesson
  • Esc — close search, images and pop-ups
